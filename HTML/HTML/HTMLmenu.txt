Τι είναι HTML ;
-----------------

Το HTML σημαίνει Hyper Text Markup Language. 

-Η HTML είναι η τυπική γλώσσα σήμανσης για τη δημιουργία ιστοσελίδων
-Η HTML περιγράφει τη δομή μιας ιστοσελίδας 
-Η HTML αποτελείται από μια σειρά στοιχείων 
-Τα στοιχεία HTML λένε στο πρόγραμμα περιήγησης πώς να εμφανίζει το περιεχόμενο 
-Τα στοιχεία HTML επισημαίνουν κομμάτια περιεχομένου όπως "αυτή είναι μια επικεφαλίδα", 
"αυτή είναι μια παράγραφος", "αυτό είναι ένας σύνδεσμος" κ.λπ.

---------------------------
Παράδειγμα δομής HTML:
---------------------------	

<!DOCTYPE html>		<-Η δήλωση ορίζει ότι αυτό το έγγραφο είναι ένα έγγραφο HTML5
<html>				<-Το στοιχείο είναι το ριζικό στοιχείο μιας σελίδας HTML
	<head>			<-Το στοιχείο περιέχει μετα-πληροφορίες σχετικά με τη σελίδα HTML
		<title>Page Title</title> <-Το στοιχείο καθορίζει έναν τίτλο για τη σελίδα HTML
	</head>
	<body>			<-Το στοιχείο ορίζει το σώμα του εγγράφου και είναι ένα κοντέινερ για όλα τα ορατά περιεχόμενα, όπως επικεφαλίδες, παραγράφους, εικόνες, υπερσυνδέσμους, πίνακες, λίστες κ.λπ.

		<h1>My First Heading</h1> <-στοιχείο ορίζει μια μεγάλη επικεφαλίδα
		<p>My first paragraph.</p> <-στοιχείο ορίζει μια παράγραφο

	</body>
</html>

---------------------------
Τι είναι ένα στοιχείο HTML;
---------------------------

Ένα στοιχείο HTML ορίζεται από μια ετικέτα έναρξης, 
κάποιο περιεχόμενο και μια ετικέτα τέλους: <tagname> Το περιεχόμενο πηγαίνει εδώ... </tagname> 

Το στοιχείο HTML είναι τα πάντα, από την ετικέτα έναρξης έως την ετικέτα τέλους: 

<h1>Η πρώτη μου επικεφαλίδα</h1> <p>Η πρώτη μου παράγραφος.</p>

|----------|-----|-------------------|----|---------|
|Start tag |     |Element content    |    |End tag  |
|----------|     |-------------------|    |---------|
|<h1>      |     |My First Heading   |    |</h1>    |
|<p>       |     |My first paragraph.|    |</p>     |
|<br>      |     |none               |    |none     |
-----------|-----|-------------------|----|---------|
