Ετικέτα:
	<code>....</code>

Επεξήγηση:
	Η ετικέτα <code> χρησιμοποιείται για να ορίσει ένα κομμάτι κώδικα υπολογιστή. 
	Το περιεχόμενο στο εσωτερικό εμφανίζεται στην προεπιλεγμένη γραμματοσειρά monospace του προγράμματος περιήγησης.
	
	*Συμβουλή: Αυτή η ετικέτα δεν έχει καταργηθεί. 
	Ωστόσο, είναι δυνατό να επιτευχθεί πιο πλούσιο αποτέλεσμα χρησιμοποιώντας CSS.

Παράδειγμα:
	<code>button</code>
