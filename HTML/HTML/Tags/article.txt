Ετικέτα:
	 <article>
	 .....
	 .....
	 .....
	 </article>

Επεξήγηση:
	Η ετικέτα <article> καθορίζει ανεξάρτητο, αυτόνομο περιεχόμενο.
	Ένα άρθρο θα πρέπει να έχει νόημα από μόνο του και θα πρέπει να είναι 
	δυνατή η διανομή του ανεξάρτητα από τον υπόλοιπο ιστότοπο. 

	Πιθανές πηγές για το στοιχείο <article>: 
	-Ανάρτηση φόρουμ 
	-Ανάρτηση ιστολογίου 
	-Ειδήσεις

	*το στοιχείο <article> δεν αποδίδεται ως κάτι ιδιαίτερο σε ένα πρόγραμμα περιήγησης.
	Ωστόσο, μπορείτε να χρησιμοποιήσετε το CSS για το στυλ του στοιχείου <article>.
Ιδιότητες:
	Πέρνει όλες της Δημόσιες Ιδιότητες

Παράδειγμα:
	<article>
		<h2>Mozilla Firefox</h2>
		<p>Mozilla Firefox is an open-source web browser developed by Mozilla. 
		Firefox has been the second most popular web browser since January, 2018.</p>
	</article>
