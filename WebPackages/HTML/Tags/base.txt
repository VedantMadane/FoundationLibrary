Ετικέτα:
	<head>
		<base href="...." target="....">
	</head>

Επεξήγηση:
	Η ετικέτα <base> καθορίζει τη βασική διεύθυνση URL και/ή τον στόχο για όλες τις σχετικές διευθύνσεις URL σε ένα έγγραφο. 
	Η ετικέτα <base> πρέπει να έχει είτε ένα χαρακτηριστικό href ή ένα χαρακτηριστικό στόχο ή και τα δύο.
	Μπορεί να υπάρχει μόνο ένα στοιχείο <base> σε ένα έγγραφο και πρέπει να βρίσκεται μέσα στο στοιχείο <head>.

Παράδειγμα:
	 <head>
		<base href="https://www.w3schools.com/" target="_blank">
	 </head>

	 <body>
		<img src="images/stickman.gif" width="24" height="39" alt="Stickman">
		<a href="tags/tag_base.asp">HTML base Tag</a>
	 </body>
