# My Library

Αυτή η βιβλιοθήκη δημιουργήθηκε με σκοπό να παρέχει ένα σύνολο
επαναχρησιμοποιήσιμων εργαλείων και δομών για την ανάπτυξη και
οργάνωση των εφαρμογών μου.

Περιλαμβάνει λειτουργίες για διαχείριση δεδομένων, repositories,
services, validation, queries, αποτελέσματα, custom types και άλλες
βοηθητικές λειτουργίες.

Η βιβλιοθήκη έχει σχεδιαστεί ώστε να είναι επεκτάσιμη και όσο το
δυνατόν ανεξάρτητη από συγκεκριμένες υλοποιήσεις.

## Περιεχόμενα

### Keys

Περιλαμβάνει interfaces που χρησιμοποιούνται για την αναπαράσταση
κλειδιών και αναγνωριστικών αντικειμένων.

Η χρήση interfaces επιτρέπει στις εφαρμογές να χρησιμοποιούν
διαφορετικούς τύπους κλειδιών χωρίς να εξαρτώνται από μία
συγκεκριμένη υλοποίηση.

### Repository

Παρέχει abstractions και λειτουργίες για την αποθήκευση και
ανάκτηση δεδομένων.

Το repository μπορεί να υλοποιηθεί με διαφορετικούς μηχανισμούς
αποθήκευσης, όπως:

- Database
- JSON
- Excel
- In-Memory storage
- Files
- άλλες πηγές δεδομένων

Με αυτόν τον τρόπο, ο υπόλοιπος κώδικας δεν χρειάζεται να γνωρίζει
πού ή με ποιον τρόπο αποθηκεύονται τα δεδομένα.

### Service

Παρέχει λειτουργίες υψηλότερου επιπέδου για τη διαχείριση των
δεδομένων.

Για παράδειγμα:

- αναζήτηση
- φιλτράρισμα
- ταξινόμηση
- δημιουργία εγγραφών
- ενημέρωση εγγραφών
- διαγραφή εγγραφών
- validation
- εφαρμογή business rules

Τα Services μπορούν να χρησιμοποιούν τα Repositories χωρίς να
εξαρτώνται από τη συγκεκριμένη τεχνολογία αποθήκευσης.

### Results

Περιλαμβάνει τύπους αποτελεσμάτων που μπορούν να χρησιμοποιηθούν
από Services, Repositories και άλλες λειτουργίες της βιβλιοθήκης.

Ένα Result μπορεί, για παράδειγμα, να περιέχει:

- κατάσταση επιτυχίας
- επιστρεφόμενο αποτέλεσμα
- μήνυμα
- πληροφορίες σφάλματος
- validation errors

### Validation

Παρέχει λειτουργίες για την επικύρωση δεδομένων.

Μπορεί να χρησιμοποιηθεί για τον έλεγχο:

- strings
- αριθμών
- μήκους δεδομένων
- μορφών
- υποχρεωτικών τιμών
- custom validation rules

Σκοπός είναι να διασφαλίζεται ότι τα δεδομένα βρίσκονται σε έγκυρη
κατάσταση πριν χρησιμοποιηθούν από την εφαρμογή.

### Types

Περιλαμβάνει τύπους δεδομένων και custom types που χρησιμοποιούνται
από τη βιβλιοθήκη.

Οι custom types μπορούν να χρησιμοποιηθούν όταν οι ενσωματωμένοι
τύποι του .NET δεν εκφράζουν επαρκώς μία συγκεκριμένη έννοια.

### ErrorLib

Παρέχει κοινές δομές για τη διαχείριση errors και exceptions.

Σκοπός είναι η ομοιόμορφη αναπαράσταση και διαχείριση σφαλμάτων
σε διαφορετικά μέρη μιας εφαρμογής.

### Query

Παρέχει δομές και λειτουργίες για τη δημιουργία queries πάνω στα
δεδομένα.

Μπορεί να χρησιμοποιηθεί για λειτουργίες όπως:

- αναζήτηση
- φίλτρα
- ταξινόμηση
- conditions
- criteria

Η πραγματική εκτέλεση ενός query μπορεί να διαφέρει ανάλογα με
την υλοποίηση του Repository.

### HTML

Περιλαμβάνει βοηθητικές δομές για τη δημιουργία και διαχείριση
HTML περιεχομένου.

Περιλαμβάνει, μεταξύ άλλων:

- HTML tags
- attributes
- HTML-related utilities

### Extensions

Περιλαμβάνει extension methods και άλλες βοηθητικές λειτουργίες
που επεκτείνουν υπάρχοντες τύπους του .NET.

### Quiz

Περιλαμβάνει δομές για τη δημιουργία και διαχείριση:

- quizzes
- ερωτήσεων
- απαντήσεων
- αποτελεσμάτων

Μπορεί να χρησιμοποιηθεί για εφαρμογές εκμάθησης ή αξιολόγησης
γνώσεων.

## Σχεδιασμός

Ένας από τους βασικούς στόχους της βιβλιοθήκης είναι η χαμηλή
σύζευξη (low coupling) μεταξύ των διαφορετικών τμημάτων της.

Όπου είναι χρήσιμο, χρησιμοποιούνται interfaces ώστε ο κώδικας
να εξαρτάται από abstractions και όχι από συγκεκριμένες
implementations.

Για παράδειγμα:

    Service
       |
       v
    IRepository
       |
       +----------------+
       |        |       |
       v        v       v
    Database   JSON   InMemory

Το Service γνωρίζει το `IRepository`, αλλά δεν χρειάζεται να
γνωρίζει αν τα δεδομένα αποθηκεύονται σε Database, JSON ή στη μνήμη.

## FAQ

### Τι σημαίνει ότι η βιβλιοθήκη είναι επεκτάσιμη;

Επεκτάσιμη σημαίνει ότι μπορούν να προστεθούν νέες υλοποιήσεις
χωρίς να χρειάζεται να αλλάξει σημαντικά ο υπάρχων κώδικας.

Για παράδειγμα, μπορεί να υπάρχει:

    IRepository

και διαφορετικές υλοποιήσεις:

    SqlRepository
    JsonRepository
    ExcelRepository
    MemoryRepository

Όλες μπορούν να ακολουθούν το ίδιο interface.

Έτσι ένα Service μπορεί να χρησιμοποιεί το `IRepository`
χωρίς να εξαρτάται από έναν συγκεκριμένο τρόπο αποθήκευσης.

### Τι είναι ένα Interface;

Ένα interface είναι μία σύμβαση (contract).

Ορίζει ποια μέλη πρέπει να παρέχει μία κλάση ή structure που
το υλοποιεί, χωρίς να καθορίζει απαραίτητα τον τρόπο με τον
οποίο θα υλοποιηθούν.

Παράδειγμα σε VB.NET:

    Public Interface IRepository(Of T)

        Function GetAll() As IEnumerable(Of T)

        Function GetById(id As Integer) As T

        Sub Add(entity As T)

        Sub Delete(entity As T)

    End Interface

Μπορούν στη συνέχεια να υπάρχουν διαφορετικές υλοποιήσεις:

    Public Class JsonRepository(Of T)
        Implements IRepository(Of T)

        ' JSON implementation

    End Class

και:

    Public Class SqlRepository(Of T)
        Implements IRepository(Of T)

        ' SQL implementation

    End Class

Και οι δύο ακολουθούν την ίδια σύμβαση, αλλά λειτουργούν με
διαφορετικό τρόπο.

### Θα υπάρχουν στο μέλλον περισσότερες λειτουργίες;

Ναι.

Η βιβλιοθήκη έχει σχεδιαστεί έτσι ώστε να μπορούν να προστεθούν
νέα components, implementations και λειτουργίες χωρίς να απαιτείται
μεγάλη αλλαγή στην υπάρχουσα αρχιτεκτονική.

## Τεχνικές πληροφορίες

- Γραμμένη σε VB.NET.
- Δεν περιλαμβάνει UI.
- Μπορεί να χρησιμοποιηθεί από Console, Desktop, Web ή άλλου τύπου εφαρμογές.
- Στόχος είναι η ελάχιστη δυνατή εξάρτηση από εξωτερικές βιβλιοθήκες.
- Χρησιμοποιεί interfaces και abstractions όπου αυτό προσφέρει
  πραγματικό πλεονέκτημα στην αρχιτεκτονική.
